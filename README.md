# Steps

Make user guides with a screenshot and a short sentence for every step recorded. Inspired by Windows' Problem Steps Recorder.

## Install

```
./build.sh install
```

## Use it

1. Click the menu bar icon and choose Start recording.
2. Pick a window or the whole screen.
3. Do the steps. Every click is captured.
4. Choose "Stop and review" from the menu bar, fix any sentence you like, delete screenshots or steps, and save the PDF.

The first time, the app walks you through the permissions it needs.
